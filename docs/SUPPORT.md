# Support

FailPack is an open-source CLI. If something breaks or the docs lie, say so.

## Channels

| Channel | Use it for |
|---|---|
| **[GitHub Issues](https://github.com/JiangSkirk/failpack/issues)** | Bugs, friction, docs drift, feature requests for the open CLI |
| **Email** — `8725598a@gmail.com` (owner **JiangSkirk**) | Private reports, account-ish questions, anything you prefer not to post publicly |

No Discord. No paid checkout in this tree. Prefer a GitHub issue when the problem is reproducible — it helps the next stranger.

## Before you open an issue

```bash
failpack --version
failpack doctor --score
failpack demo --fast
```

Paste the version string, the readiness score line, and the shortest command sequence that failed. Fixtures-only reports are fine; do not attach live agent secrets.
