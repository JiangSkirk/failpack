The problem

Agent failures live in chat scrollback. Next week the same bad edit or tool path shows up again — and CI stays green. You don’t need another heavy eval platform. You need one failure → one regression that blocks merge.

Quickstart

The ~60-second stranger path:

pip install failpack
failpack demo --fast
failpack demo --claude-hermetic

# optional git fallback
# pip install "git+https://github.com/JiangSkirk/failpack.git"

That runs capture → promote → replay on a bundled fixture. demo --claude-hermetic proves capture --claude-latest without a Claude binary. Optional next: real failpack capture --claude-latest, promote --suggest, then CI replay. Not a security gate. Not a second agent. A regression pack you own in git.

How it works

  1. Capture a Claude Code–style JSONL failure transcript into a pack
  2. Promote fingerprints + expected error signals to golden
  3. Replay locally or in CI — drift fails the build
